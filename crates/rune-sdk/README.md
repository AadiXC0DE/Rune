# rune-sdk

Embed the Rune coding agent in a Rust program: your credential, tools and network path.

This is the entry point for a Rust program that embeds Rune: build an `Agent`
with the credential, model, tools and endpoint, then `prompt` it. The other
`rune-*` crates are its parts and are published so it can depend on them.

See the repository for the command-line program and its documentation:
https://github.com/AadiXC0DE/Rune
