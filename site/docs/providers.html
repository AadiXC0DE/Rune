Providers

Each preset names an endpoint and the variable its key is read from. rune connect <name> connects one; rune connect alone chooses from a list. The configuration shown is the smallest file that selects the preset.

anthropic

Anthropic Messages API. Dialect: anthropic. Direct from the model vendor; API key.

rune connect anthropic
  • Endpoint: https://api.anthropic.com.
  • Key variable: ANTHROPIC_API_KEY.
provider = "anthropic"

[models]
anthropic = "<model id>"

openai

chat_completions

Any OpenAI-compatible Chat Completions endpoint. Dialect: chat_completions. Any compatible endpoint; API key.

rune connect chat_completions
  • Endpoint: none built in; set base_url.
  • Key variable: OPENAI_API_KEY.
provider = "chat_completions"
base_url = "<endpoint>"

[models]
chat_completions = "<model id>"

ollama

Local Ollama models, native discovery and Chat Completions requests. Dialect: chat_completions. Local servers; no credential (loopback only).

rune connect ollama
  • Endpoint: http://127.0.0.1:11434/v1.
  • No key: the server is reached on this machine only.
provider = "ollama"
anonymous = true

[models]
ollama = "<model id>"
