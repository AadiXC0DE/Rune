A coding agent in one 3 MiB binary.

Native Rust, sandboxed, and model agnostic. It starts in about 2 ms, and every rule it applies names the file that set it.

This is Rune, running in the page.

The same Rust as the binary, compiled to WebAssembly: the turn loop, the tools, and the permission rules, in about 540 KB. The files live in the tab. Watch it fix a bug, then type your own request.

The binary runs commands in a real sandboxed shell; a tab cannot start programs, so here commands run in a small shell over the same files. The permission prompt is the harness asking, and the turn waits for your answer.

Small on purpose, and held there.

Each of these is enforced by a test or a build step, not a promise.

A budget, not an aspiration
Binary size and startup are measured on every pull request against a ceiling of 8 MiB and 5 ms. The build fails when either is crossed.
Commands run in a sandbox
Seatbelt on macOS, bubblewrap on Linux. Writes stay in the workspace, credential files cannot be read, and rune doctor says what your machine enforces.
Every decision names its source
A limit, a rule, a setting: rune permissions and rune config --explain answer which file decided, rather than restating the value.
Steer a turn while it runs
Type while the model works and the correction reaches it at the next step. Escape twice cancels, and the session carries on.
Any model, no account
Anthropic, OpenAI, OpenCode, or any OpenAI-compatible endpoint, hosted or on your machine. No telemetry, and --offline refuses every request.
One harness, several hosts
The terminal, rune ask in a script, an editor over the Agent Client Protocol, a Rust library, and the tab above.

Start in three commands.

A fresh install has no provider, so connect lists them and asks for what it needs.

$ brew install aadixc0de/tap/rune   # or cargo install, see above
$ rune connect                      # choose a provider and paste its key
$ rune                              # start a session in this directory
