Why Rune

Small on purpose, and held there.

Each of these is enforced by a test or a build step, not a promise. The snippets are the binary's own output.

01A budget, not an aspiration

Every pull request measures the binary, the startup work, and the prompt, and the build fails when a ceiling is crossed.

binary5.45 / 8 MiB
prompt1.2 / 6 KiB

Binary: the audited stripped build for x86_64 Linux. Prompt: as assembled in a fresh git repository.

how it is measured

Every pull request checks an 8 MiB binary size ceiling and startup work ceilings of 2 ms for --version and --help. Work uses the baseline-subtracted minimum-of-31, clamped to zero: the baseline is system true on Unix and an empty Rust executable on Windows. If no baseline is available, the budget fails because startup work ceilings cannot be enforced. Budget output also reports raw process latency minimum, median and p95. It assembles the system prompt from the checkout and checks it against a 6 KiB per-turn ceiling. The build fails when a ceiling is crossed.

02Commands run in a sandbox

Seatbelt on macOS, bubblewrap on Linux. Writes stay in the workspace, credential files cannot be read, and rune doctor says what your machine enforces.

$ rune doctor
ok  sandbox  seatbelt restricts every process the command starts
ok  network  commands have no network access (default)

03Every decision names its source

A limit, a rule, a setting: rune permissions and rune config --explain answer which file decided, rather than restating the value.

$ rune permissions --explain shell:pwd
shell `pwd`: allowed (allow: matched `shell pwd` at the default layer); source: built in

04Steer a turn while it runs

Type while the model works and the correction reaches it at the next step. Escape twice cancels, and the session carries on.

type steeresc esc cancel

05Any model, no account

Anthropic, OpenAI, OpenCode, or any OpenAI-compatible endpoint, hosted or on your machine. No telemetry. --offline blocks provider and web requests, skips remote MCP checks and restricts sandboxed shell networking. Local MCP and unsandboxed commands can still use the network.

anthropicopenaiopencodeopenai-compatiblelocalhost

Install

Start in three commands.

A fresh install has no provider, so connect lists them and asks for what it needs.

  1. $brew install aadixc0de/tap/rune

    Or cargo install, see above.

  2. $rune connect

    Choose a provider and paste its key.

  3. $rune

    Start a session in this directory.

Put it in your terminal.

Apache-2.0, no account, no telemetry. Bring any model, keep every rule in a file you can read.
